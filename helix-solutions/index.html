How it works

Operational Control Plane: from request to recorded outcome.

  1. Submit

    Manager raises request.

  2. Gate

    Unverifiable controls deny.

  3. Approve

    Second reviewer decides.

  4. Execute

    Runs with correlation id on every write.

  5. Audit

    Recorded in the trail.
